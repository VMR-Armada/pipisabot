# Линейка

Свой игровой бот в духе Pipisa Bot: для групповых чатов, отдельно от официального @pipisabot.

Раз в календарный день `/dick` меняет длину на случайное целое число от −5 до +10 см. Новый день открывает замер сразу, без ожидания полных 24 часов. В каждом чате длина своя. Есть топ чата, общий топ и карточка статистики. День считается по часовому поясу `TIMEZONE`, по умолчанию Москва.

## Запуск

1. В Telegram открой [@BotFather](https://t.me/BotFather) и создай бота командой `/newbot`.
2. Скопируй `.env.example` в `.env` и вставь токен в `BOT_TOKEN`.
3. Установи зависимости и запусти:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python -m pipisa
```

4. Добавь бота в группу. Команды он видит и с включённым privacy mode. Если молчит, проверь, что ему можно писать в чат.

При старте бот сбрасывает сообщения, которые пришли, пока он был выключен, чтобы старый `/dick` не съел сегодняшний замер.

## Команды

| Команда | Что делает |
| --- | --- |
| `/dick` | Замер: от −5 до +10 см |
| `/top_dick` | Топ 10 текущего чата |
| `/top10_pics` | Топ 10 текущего чата картинкой: слева самый большой размер, справа самый маленький |
| `/global_top` | Топ 10 по всем чатам. Если игрок есть в этом чате, показывается его размер здесь |
| `/global_top_pic` | Тот же глобальный топ картинкой: слева самый большой размер, справа самый маленький |
| `/stats` | Карточка статистики |
| `/day_review` | Шуточные итоги дня в этом чате: каждый замер по времени, плюс дуэли и баттлкапы |
| `/week_review` | То же за неделю, с понедельника |
| `/duel` | Дуэль ответом на сообщение или через `/duel @ник`. Соперник соглашается, оба бросают кубик 1–6, победитель забирает разницу. Вызов можно отменить, пока его не приняли |
| `/ffa` | Открытый вызов: принять может любой участник, который уже делал замер |
| `/battlecup` | Турнир через 10 минут, свои минуты — `/battlecup 5`. Кнопка «Присоединиться» ставит 2 см. Пять бросков по очереди, следующий раунд через минуту. Банк забирает большая сумма, несколько первых делят его поровну |
| `/clear 20` | Удалять сообщения бота старше 20 минут. Непринятые дуэли остаются до ответа. Объявление баттлкапа остаётся, пока турнир не начался |
| `/help` | Справка |
